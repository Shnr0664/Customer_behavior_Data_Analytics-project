# Customer Shopping Behavior Analysis

### End-to-End Data Analytics Project | Python • PostgreSQL • SQL • Power BI

## Overview

This project explores customer shopping behavior to identify purchasing patterns, revenue drivers, product preferences, and differences across customer segments.

Using a dataset of **3,900 customer records**, I performed data cleaning and feature engineering with Python, conducted business-oriented analysis using PostgreSQL, and developed an interactive Power BI dashboard to visualize the results.

The project demonstrates an end-to-end data analytics workflow, from raw data preparation to business insights and reporting.

## Tech Stack

- **Python (Pandas, NumPy):** Data exploration, cleaning, and feature engineering
- **PostgreSQL:** Data storage and SQL-based analysis
- **SQL:** Aggregations, CTEs, subqueries, window functions, and customer segmentation
- **Power BI:** Interactive dashboards and KPI visualization
- **Jupyter Notebook:** Exploratory analysis and documentation

## Business Questions

The analysis addresses several business questions:

- How does revenue vary across customer demographics?
- Do subscribed customers spend more than non-subscribers?
- Which products perform best in terms of popularity and customer ratings?
- How do discounts and shipping methods relate to purchasing behavior?
- How does subscription participation differ across customer purchase-history segments?

## Project Workflow

**1. Data Cleaning & Preparation (Python)**

- Explored 3,900 customer records and assessed data quality.
- Handled missing review ratings using category-level median imputation.
- Standardized column names and removed redundant features.
- Engineered age-group and purchase-frequency features.

**2. Business Analysis (PostgreSQL)**

- Loaded the cleaned dataset into PostgreSQL.
- Developed 10 SQL queries addressing business questions.
- Analyzed customer segments, spending behavior, subscriptions, discounts, and product performance.

**3. Data Visualization (Power BI)**

- Developed an interactive dashboard to visualize key customer and sales metrics.
- Used charts, KPIs, and filters to support business reporting.

**4. Insights & Recommendations**

- Interpreted analytical results and documented findings.
- Developed business recommendations based on customer purchasing patterns.
- Prepared a detailed project report and presentation.
